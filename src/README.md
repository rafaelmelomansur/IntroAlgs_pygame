# Código-fonte (`src`)

Esta pasta contém os módulos principais do jogo.

## Arquivos

- `engine.py`: gerencia o loop do jogo, telas, dificuldade e renderização.
- `entities.py`: classes dos sprites do jogo (Jogador, Meteoro, Cristal).
- `settings.py`: constantes globais (tela, cores, velocidades, configurações).
- `utils.py`: funções de leitura e gravação de dados (recorde e ranking).
- `funcoes.py`: funções auxiliares puras de regra e lógica, isoladas para testes.
